## 4. パフォーマンス・リソース計画

- [ ] 一覧系の問い合わせ API はデフォルトでページネーションし、全件スキャンを禁止
- [ ] データベース設計と同時にインデックス設計を出力
- [ ] 大容量ファイル/大規模データ処理はストリーミング処理
- [ ] 大規模メモリ操作には明確な解放機構がある
- [ ] 外部リクエストにはタイムアウトとリトライを設定
