# フロントエンド UI 要素マッピング表 + イベントマッピング表（フロントエンド実装前に必須）

> メンター AI がフロントエンド実装前に出力し、「プログラミング未経験のユーザー」が正確に問題を報告できるようにするものです。
> 完成後は `docs/` に保存し、API 仕様書（`docs/api_interface.md`）と併用してください。

## 1. ページワイヤーフレーム（ASCII または Mermaid）

```
┌──────────────────────────────────────────┐
│  トップナビゲーション（ロゴ / メニュー / アバター）│
├───────────────┬──────────────────────────┤
│               │                          │
│   サイドバー  │     メインコンテンツ     │
│               │                          │
└───────────────┴──────────────────────────┘
```

## 2. UI 要素マッピング表

| 画面上の位置 | コンポーネント名 | 対応ファイルパス | CSS クラス/ID | 機能説明 |
|-------------|-----------------|------------------|--------------|---------|
| トップナビ右側 | UserAvatar | src/components/Header.tsx | .user-avatar | ユーザーアバターとドロップダウンメニュー（ログアウト、プロフィール） |
| | | | | |

## 3. フロントエンド イベントマッピング表

| 名称 | 操作（クリック/スワイプ/入力） | 呼び出すバックエンド API | 期待される結果 |
|------|-------------------------------|--------------------------|----------------|
| ログインボタン | クリック | POST /api/login | 検証成功でホームへ遷移、失敗時はエラー表示 |
| | | | |

## 4. 使い方（プログラミング未経験者向け）

1. ページの問題を報告するときは「**位置** + **現象**」の形で伝えてください。例：
   > 「トップナビ右側のアバターがクリックに反応しない」
2. メンター AI が上記 2 つの表から該当するコンポーネントと API を特定するため、コードの説明は不要です。
