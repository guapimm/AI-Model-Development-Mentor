# Таблица соответствия элементов UI + таблица соответствия событий (обязательна перед написанием фронтенда)

> Выдаётся ИИ-наставником перед написанием фронтенд-кода, чтобы «новички без опыта» могли точно сообщать о проблемах.
> После заполнения сохраните в `docs/` и используйте вместе со спецификацией API (`docs/api_interface.md`).

## 1. Каркас страницы (ASCII или Mermaid)

```
┌──────────────────────────────────────────┐
│  Верхняя панель навигации (логотип / меню / аватар) │
├───────────────┬──────────────────────────┤
│               │                          │
│   Боковая     │     Основной контент     │
│   панель      │                          │
└───────────────┴──────────────────────────┘
```

## 2. Таблица соответствия элементов UI

| Положение на экране | Компонент | Путь к файлу | CSS-класс/ID | Описание |
|---------------------|-----------|--------------|--------------|----------|
| Верхняя панель, справа | UserAvatar | src/components/Header.tsx | .user-avatar | Аватар пользователя и выпадающее меню (выход, профиль) |

## 3. Таблица соответствия событий фронтенда

| Название | Действие (клик/свайп/ввод) | Вызываемый API бэкенда | Ожидаемый результат |
|----------|-----------------------------|------------------------|---------------------|
| Кнопка входа | Клик | POST /api/login | После проверки — переход на главную, при ошибке — сообщение |
| | | | |

## 4. Инструкция по использованию (для новичков без опыта)

1. Чтобы сообщить о проблеме на странице, просто скажите «**положение** + **что произошло**», например:
   > «Аватар в правом верхнем углу не реагирует на клик»
2. ИИ-наставник найдёт нужный компонент и эндпоинт по двум таблицам выше — описывать код не нужно.
