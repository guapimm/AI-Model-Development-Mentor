# 프런트엔드 UI 요소 매핑표 + 이벤트 매핑표（프런트엔드 작성 전 필수）

> 멘토 AI가 프런트엔드 작성 전에 출력하여 '프로그래밍 초보 사용자'가 정확히 문제를 보고할 수 있게 합니다.
> 완성 후 `docs/`에 보관하고 API 명세(`docs/api_interface.md`)와 함께 사용하세요.

## 1. 페이지 와이어프레임（ASCII 또는 Mermaid）

```
┌──────────────────────────────────────────┐
│  상단 내비게이션(로고 / 메뉴 / 아바타)      │
├───────────────┬──────────────────────────┤
│               │                          │
│   사이드바    │     메인 콘텐츠           │
│               │                          │
└───────────────┴──────────────────────────┘
```

## 2. UI 요소 매핑표

| 화면 위치 | 컴포넌트 이름 | 해당 파일 경로 | CSS 클래스/ID | 기능 설명 |
|-----------|--------------|----------------|---------------|-----------|
| 상단 내비게이션 오른쪽 | UserAvatar | src/components/Header.tsx | .user-avatar | 사용자 아바타 및 드롭다운 메뉴(로그아웃, 개인정보) |
| | | | | |

## 3. 프런트엔드 이벤트 매핑표

| 이름 | 동작(클릭/스와이프/입력) | 호출하는 백엔드 API | 예상 결과 |
|------|--------------------------|---------------------|-----------|
| 로그인 버튼 | 클릭 | POST /api/login | 검증 성공 시 홈으로 이동, 실패 시 오류 표시 |
| | | | |

## 4. 사용 안내（프로그래밍 초보자용）

1. 페이지 문제를 보고할 때는「**위치** + **현상**」형식으로 말하세요. 예:
   > "상단 내비게이션 오른쪽의 아바타가 클릭에 반응하지 않아요"
2. 멘토 AI가 위의 두 표로 해당 컴포넌트 파일과 API를 찾아내므로 코드를 설명할 필요가 없습니다.
