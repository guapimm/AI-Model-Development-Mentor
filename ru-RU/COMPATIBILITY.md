# Инструкция по загрузке для каждого ИИ-инструмента (руководство по совместимости)

Содержимое промптов в каталоге `prompts/` **не привязано** к конкретному ИИ-инструменту — его может использовать любой инструмент для кодинга на основе больших языковых моделей. Разница только в **способе загрузки**: имя главного файла, место хранения, команда загрузки. Этот файл — как раз «один файл с инструкциями по загрузке»: чтобы добавить новый инструмент, достаточно дописать здесь одну строку.

> Подсказка: все инструменты можно установить одной командой через CLI `mentor` (файлы автоматически записываются в правильные места для каждого инструмента) — см. конец файла.

## Подробности по каждому инструменту

### opencode
1. Скопируйте `prompts/AGENTS.md` в корень проекта
2. opencode автоматически загружает AGENTS.md в каждой сессии — ручных действий не требуется
3. Когда нужны безопасность/стиль/рабочий процесс: загружайте по мере необходимости `@security.md`, `@style.md`, `@workflow.md`
4. Для долгосрочных проектов: храните правила в AGENTS.md; при обрыве связи восстанавливайтесь командой `opencode --continue`

### Claude Code
1. Скопируйте `prompts/AGENTS.md` → переименуйте в `CLAUDE.md` (или оставьте как `AGENTS.md` — новые версии распознают его автоматически)
2. Положите в корень проекта — будет загружаться автоматически в каждой сессии
3. Остальные модули указывайте в `CLAUDE.md` через ссылку `@security.md` или просто добавляйте содержимое прямо в файл
4. `CLAUDE.md` во вложенных каталогах загружается по мере необходимости при входе в этот каталог

### OpenAI Codex
1. Скопируйте `prompts/AGENTS.md` в корень проекта (Codex автоматически загружает `AGENTS.md` из корня)
2. Остальные модули указывайте в `AGENTS.md` через ссылку `@security.md`
3. Для восстановления после обрыва используйте `codex --resume` (или `codex exec --resume`)

### Cursor
1. Скопируйте `prompts/AGENTS.md` в каталог `.cursor/rules/` (Agent автоматически загружает rules)
2. Чтобы правило действовало только на определённые файлы, можно перевести его в формат `.mdc` и добавить в frontmatter `globs`
3. Одноимённые файлы остальных модулей тоже положите в `.cursor/rules/`

### Gemini CLI
1. Скопируйте `prompts/AGENTS.md` → переименуйте в `GEMINI.md`, положите в корень проекта — загружается автоматически
2. Остальные модули можно объединить в `GEMINI.md` или ссылаться на них через `@` по мере необходимости

### Google Jules
1. Скопируйте `prompts/AGENTS.md` → переименуйте в `JULES.md`, положите в корень проекта — загружается автоматически

### Aider
1. Скопируйте `prompts/AGENTS.md` → переименуйте в `CONVENTIONS.md`, положите в корень проекта — автоматически загружается в сессиях редактирования

### Windsurf
1. Скопируйте `prompts/AGENTS.md` → переименуйте в `.windsurfrules`, положите в корень проекта — загружается автоматически

### GitHub Copilot Agent
1. Скопируйте `prompts/AGENTS.md` в корень проекта — загружается автоматически; остальные модули указывайте через ссылку `@security.md`

### MCP (Model Context Protocol)
1. Соберите сервер: `cd mcp && npm install && npm run build`
2. Укажите MCP-клиенту `node <repo>/mcp/dist/index.js`
3. Сервер предоставляет промпты как ресурсы (`mentor://prompts/{lang}/{module}`) и инструменты (`install`, `detect_tool`, `list_languages`, `list_modules`, `generate_resource_estimate`)
4. Подробнее см. `mcp/README.md`

## Установка одной командой через CLI mentor

```bash
mentor install          # интерактивно: выбрать язык → выбрать модули (по умолчанию agent) → автоматически определить/выбрать инструмент
mentor install --lang zh-CN --modules agent,security --cli claude-code
mentor add workflow     # добавить модуль
mentor list             # посмотреть установленные модули
```

`mentor` автоматически записывает файлы в те имена и места, которые требует каждый инструмент, по правилам из таблицы выше (Claude Code → `CLAUDE.md`, Cursor → `.cursor/rules/`, остальные → `AGENTS.md` и т.д.).

## Полная версия промпта

Если не нужно разбивать на модули, можно напрямую использовать `prompts/Полный-промпт-наставника.md` (объединённая версия всех четырёх модулей, загружается одним разом).
