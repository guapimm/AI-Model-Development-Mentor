# AI Model Mentor (Русский)

> **Превратите вашего AI-кодинг-ассистента в осторожного full-stack наставника с 10-летним опытом — чистые промпты, ноль зависимостей.**

---

## Что это?

**Чисто-промптовая (Prompt) фреймворк-система**, которая превращает вашего AI-кодинг-ассистента в **full-stack архитектора и наставника по разработке с 10-летним опытом**, созданную для новичков в программировании с нулевой базой.

Она заставляет AI соблюдать набор «железных правил» — делая *Безопасность прежде всего, Прозрачную логику, Документацию прежде всего, Эффективность Token и Поэтапную реализацию* поведением по умолчанию. Результат: AI, который не просто *пишет код*, а пишет **безопасный, поддерживаемый, документированный** код.

> ⚠️ В настоящее время поддерживается платформа: **Xiaomi MIMO CLI**. Оптимизированные сборки для других продуктов (Claude Code, Cursor и др.) в планах — оставьте комментарий в репозитории, если вам нужна такая.

### 6 железных правил

1. **Код — это документация** — весь код несёт комментарии, объясняющие «почему»
2. **Безопасность прежде всего** — никаких хардкод-секретов, строгая валидация ввода, параметризованные запросы, защита от XSS
3. **Ноль разрушительных изменений** — сначала проанализируйте зависимости, помечайте правки как 【Обязательное изменение】/【Опциональная оптимизация】
4. **Поэтапное выполнение** — не более 300 строк за один вывод, на каждом шаге — ожидание подтверждения
5. **Модульная изоляция** — не более 500 строк на файл, оставляйте интерфейсы расширения
6. **Эффективность Token** — после каждого диалога формируйте 【Сводку контекста】 и 【Пароль для продолжения】

## 📖 Руководство по использованию (MIMO CLI)

### Команды (шпаргалка)

| Сценарий | Действие |
|------|------|
| Ежедневная разработка | Войдите в проект → `/skill AGENTS.md` → обычный диалог |
| Долгосрочный проект | После первой загрузки закрепите правила в MEMORY.md с помощью `/dream` |
| Неожиданный разрыв связи | Восстановитесь через `mimo --continue`, правила skill сохранятся |
| Намеренно новое открытие сессии | После `/new` не забудьте снова выполнить `/skill AGENTS.md` |

### Конкретные сценарии

#### Сценарий 1: повседневное написание кода (загружен только AGENTS.md)

> Вы: «Помоги мне написать API для получения списка пользователей»

Нужно загрузить: AGENTS.md (уже загружен автоматически, действия не требуются)

AI автоматически:

- Код с комментариями на русском языке
- Отмечает чек-лист безопасности перед выводом
- Выполняет пошагово (≤300 строк)
- Один файл ≤500 строк

#### Сценарий 2: написание API входа/регистрации (загрузить AGENTS.md + security.md)

> Вы: «Помоги мне написать функцию входа пользователя, сделай по требованиям security.md»

Нужно загрузить:

```bash
/skill security.md
```

AI дополнительно:

- Хранит пароли в виде хеша bcrypt
- Устанавливает время истечения для JWT Token
- Защита от brute force (ограничение неудачных попыток входа)
- Защита от SQL-инъекций (параметризованные запросы)

#### Сценарий 3: запуск проекта с нуля (загрузить AGENTS.md + workflow.md)

> Вы: «Я хочу сделать блог-систему, помоги мне собрать каркас проекта по workflow.md»

Нужно загрузить:

```bash
/skill workflow.md
```

AI дополнительно:

- Создаёт docs/architecture.md (выбор технологического стека + схема архитектуры)
- Создаёт docs/dev_log.md (шаблон журнала разработки)
- Создаёт docs/api_interface.md (шаблон контрактов интерфейсов)
- Создаёт docs/SNAPSHOT.md (снимок проекта)
- Генерирует скрипты backup.sh и rollback.sh

#### Сценарий 4: AI объясняет слишком запутанно (загрузить style.md)

> Вы: «Объясни мне, что такое JWT, в стиле style.md, с помощью бытовых аналогий»

Нужно загрузить:

```bash
/skill style.md
```

AI дополнительно:

- Объясняет JWT через «карту постоянного клиента ресторана»
- Добавляет фазовый тег [📋 Анализ требований]
- Сначала даёт вывод, потом детали
- Предлагает 2–3 варианта решения

#### Сценарий 5: развёртывание и запуск (загрузить AGENTS.md + workflow.md)

> Вы: «Напиши мне Docker-конфигурацию для развёртывания по правилам workflow.md»

Нужно загрузить:

```bash
/skill workflow.md
```

AI дополнительно:

- Разделяет конфигурации окружений разработки и production
- Генерирует docker-compose.yml
- Генерирует health_check.sh
- Напоминает о шагах резервного копирования и отката

### ⚠️ Когда НЕ загружать?

| Когда не нужно загружать | Причина |
|---------------|------|
| Чисто технический вопрос (например, «как использовать React useEffect») | AGENTS.md достаточно, добавление workflow только мешает |
| Правка одного CSS-стиля | Не нужны правила безопасности и процесс развёртывания |
| Попросить AI перевести текст | Никакой skill вообще не нужен |
| Простой рефакторинг существующего кода | Чек-лист безопасности AGENTS.md уже покрывает |

### 💡 Итог в одной фразе

> AGENTS.md — это скин по умолчанию, а остальные три — эффектные плагины: включайте их только когда нужно, в обычное время не включайте — экономия Token и чистота.

## Быстрый старт (3 шага)

```bash
# 1. Скопируйте роль наставника в свой проект (переименуйте в AGENTS.md)
cp prompts/AGENTS.md AGENTS.md

# 2. (Рекомендуется) Добавьте также спецификации безопасности/стиля/рабочего процесса
cp prompts/security.md security.md
cp prompts/style.md style.md
cp prompts/workflow.md workflow.md
```

3. Запустите Xiaomi MIMO и скажите:

> «Я полный новичок. Вот моя 【Спецификация требований к проекту】: название проекта ____, основная цель ____, роли пользователей ____, основные операции ____, обязательные к хранению данные ____. Начните с Этапа 0: подготовка окружения и выбор технологического стека и ведите меня пошагово.»

AI будет продвигаться по схеме «Дизайн → Основная логика → Интерфейс → Тестирование», ожидая вашего подтверждения на каждом этапе.

## FAQ

**В: Нужны ли мне все 4 модуля?**
О: Нет. `AGENTS.md` — единственный обязательный. Добавьте `security.md` для более надёжной защиты, `style.md` для более дружелюбного общения.

**В: Работает ли это с другими AI-продуктами?**
О: Пока поддерживается только Xiaomi MIMO. Оптимизированные версии для других продуктов в разработке — оставьте комментарий, чтобы сообщить нам, что вам нужно.

**В: Это переведено машинным способом?**
О: Все языковые версии — это выверенные переводы одного китайского оригинала. Если вы заметили неточность, смело открывайте issue или PR.
